# Trip Planning Brief (reusable)

Reusable planning profile + playbook for this family's road trips. Country-specific plans live in their own files (see **Trips index** below). Keep this file **abstract** so it works for any destination.

## Travelers & constraints
- **Family of 4:** 2 adults, child (**8 yrs**), baby (**6 months**). *Update ages per trip.*
- **Car:** rental **SUV (~Hyundai Tucson size, ~1.65 m tall)** → prefer **spacious open-air lots**; garages fine (clears the usual ~2.0 m limits).
- **Preferences:**
  - A **swim every day** where the season allows.
  - **Short flat walks only** — baby in a **carrier**; avoid long/steep hikes.
  - **Early starts OK** — beat heat, crowds, and parking pressure.
  - **Budget-conscious** — skip pricey cable cars/cog railways when a cheaper view or experience exists.
  - **Local food** welcome.
- **Practical:** coins for parking machines; check **road tolls/vignette** per country (and whether included with the rental).

## Planning principles (playbook)
- **One central base**; day-trip out. Cluster stops geographically, ~2–3 per day.
- **Parking:** name the *actual* car park, not the attraction (they differ). Always list a **primary → backup** lot for every stop. Prefer large open-air lots for the SUV. **Verify the exact pin.** Note **morning-only** lots (fill early) vs **evening-friendly**, plus local **free-evening/Sunday** rules.
- **Timing:** nature/mountains + crowded icons in the **morning** (cooler, storm-free, easier parking); **cities in the evening** (cooler, lit, cheaper/free parking, dinner).
- **Kid/baby filters:** skip caves/mines (age limits), long loop hikes, expensive cable cars; favor **lakes/swims, flat lakeside walks, castles with falconry/fountains, passenger-boat cruises**.
- **Verify before locking:** closures/renovations, opening hours, show/tour times, boat timetables, tolls.

## Reusable prep & follow-up checklist
- [ ] Confirm **opening hours + show/tour times** for anchor sights.
- [ ] **Verify closures/renovations** at headline attractions.
- [ ] Check **boat/cable-car timetables** (and whether cheaper than the alternative).
- [ ] **Tolls/vignette:** confirm if included with the rental; buy online if not.
- [ ] Reserve **dinner** in busy towns if needed.
- [ ] Confirm **exact parking pins**; note morning-only vs evening-OK.
- [ ] Pack: **baby carrier**, swimwear/towels, sun hats + high-SPF, light rain layer, coins for parking.
- [ ] Weather rule: **nature in the morning** (afternoon thunderstorms common in summer mountains).

## Building a Google Maps list
Use name-search links — Google geocodes the exact place, which is more reliable than hand-entered coordinates:

`https://www.google.com/maps/search/?api=1&query=<place name>`

Save each into a per-trip list and confirm the pin when saving.
